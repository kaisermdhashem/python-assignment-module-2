## Assignment 1: Student Grade Calculator

**File:** `student_grade_calculator.py`

### Description
A Python program that takes a student's name and marks in three subjects, calculates the total and average marks, and determines the final grade based on the average.

### Features
- Takes the student's name as input.
- Accepts marks for three subjects.
- Calculates total and average marks.
- Determines grades using conditional statements.

### Grading Criteria

| Average Marks | Grade |
|---|---|
| 80–100 | A+ |
| 70–79 | A |
| 60–69 | B |
| 50–59 | C |
| Below 50 | F |

## Assignment 2: Simple Shopping Cart

**File:** `shopping_cart.py`

### Description
A Python program that takes a customer's name and the names and prices of three products, calculates the subtotal, applies a discount based on the purchase amount, and displays the final payable amount.

### Features
- Takes customer information as input.
- Accepts three product names and prices.
- Calculates the subtotal.
- Applies discounts based on the subtotal.
- Calculates the final total after discount.
- Displays a formatted shopping summary.

### Discount Criteria

| Subtotal | Discount |
|---|---|
| 5000 or above | 20% |
| 3000–4999 | 10% |
| 1000–2999 | 5% |
| Below 1000 | No discount |

### Calculation Formula

- **Subtotal** = Sum of all product prices
- **Discount** = Subtotal × Discount Rate
- **Final Total** = Subtotal − Discount
